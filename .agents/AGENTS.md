# Reglas del Agente / Agent Rules

- **No realizar cambios no solicitados**: No realices modificaciones en el código o en los archivos del proyecto a menos que el usuario lo solicite explícitamente.
- **Enfoque educativo**: Si el usuario indica que está en un proceso de aprendizaje o pregunta cómo funciona algo, explica detalladamente el funcionamiento del código y los conceptos teóricos o prácticos asociados.
- **No tocar la base de datos sin autorización explícita**: Queda estrictamente prohibido alterar, consultar directamente, ejecutar migraciones, scripts o interactuar de cualquier forma con la base de datos (Supabase u otra) a menos que el usuario lo solicite explícitamente.
